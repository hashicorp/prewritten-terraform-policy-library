# Delete Network Security Group Activity Log Alert

| Provider | Category               |
| -------- | ---------------------- |
| Azure    | Logging and monitoring |

## Description

CIS Azure Foundations v6.0.0 control 6.1.2.4 evaluates declared activity-log alerts for `Microsoft.Network/networkSecurityGroups/delete`. Matching alerts must be enabled, use the Administrative category, include subscription scope, notify an action group, and avoid additional narrowing criteria.

Operation names are normalized for case and whitespace. Scopes must include a subscription; omitted, null, or empty scopes fail. Notification actions must include a nonblank action-group ID; omitted, null, or blank IDs fail. Genuine Terraform unknown values remain unresolved until known.

**Coverage:** This resource-level policy cannot detect a missing alert or prove that notifications are delivered.

Requires `hashicorp/azurerm >= 4.0.0, < 6.0.0`. Enforcement defaults to `advisory`, configurable through `delete-nsg-alert-enforcement-level`.

This rule is covered by the [delete-nsg-alert](../../../policies/azure/monitor/delete-nsg-alert.policy.hcl) policy.
