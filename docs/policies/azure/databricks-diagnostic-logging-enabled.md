# Ensure that Diagnostic Log Delivery is Configured for Azure Databricks

| Provider | Category |
| -------- | -------- |
| Azure    | Logging and monitoring |

## Description

This control checks that every Azure Databricks workspace uses the Premium SKU and sends diagnostic logs to a destination. It evaluates `azurerm_databricks_workspace` resources and looks for `azurerm_monitor_diagnostic_setting` resources whose `target_resource_id` matches the workspace ID. Across those settings, the `accounts`, `Filesystem`, `clusters`, `notebook`, and `jobs` log categories (or the `allLogs` category group) must be enabled, and each setting that provides them must route logs to Log Analytics, a Storage account, or an Event Hub.

Diagnostic logs are only available on the Premium SKU and give an audit trail of workspace, cluster, notebook, and job activity. A Standard workspace, a diagnostic setting without a destination, or a setting missing any required category does not meet the control.

This rule is covered by the [databricks-diagnostic-logging-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/databricks/databricks-diagnostic-logging-enabled.policy.hcl) policy.
