# Ensure That Microsoft Defender for Azure SQL Databases Is Set to 'On'

| Provider | Category |
| -------- | -------- |
| Azure    | Security posture management |

## Description

This control checks that Microsoft Defender for Azure SQL Databases is enabled at the Standard tier. It evaluates `azurerm_security_center_subscription_pricing` resources with `resource_type = "SqlServers"`.

The Standard tier enables Defender protections for Azure SQL databases. A Free tier, missing tier, or pricing resource for a different plan does not satisfy this requirement.

This rule is covered by the [defender-sql-databases-on](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/security-center/defender-sql-databases-on.policy.hcl) policy.
