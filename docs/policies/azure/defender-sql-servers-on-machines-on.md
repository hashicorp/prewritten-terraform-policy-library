# Ensure That Microsoft Defender for SQL Servers on Machines Is Set to 'On'

| Provider | Category |
| -------- | -------- |
| Azure    | Security posture management |

## Description

This control checks that Microsoft Defender for SQL servers on machines is enabled at the Standard tier. It evaluates `azurerm_security_center_subscription_pricing` resources with `resource_type = "SqlServerVirtualMachines"`.

The Standard tier enables Defender protections for SQL Server instances running on virtual machines. Other Defender plans, including the separate Azure SQL Databases plan, are outside this policy's scope.

This rule is covered by the [defender-sql-servers-on-machines-on](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/security-center/defender-sql-servers-on-machines-on.policy.hcl) policy.
