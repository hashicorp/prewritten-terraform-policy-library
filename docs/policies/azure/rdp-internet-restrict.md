# Ensure that RDP Access from the Internet is Evaluated and Restricted

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks whether Azure Network Security Group inline rules allow inbound TCP traffic on port 3389 (Remote Desktop Protocol) from Internet-level sources. Unrestricted RDP access from the public internet is one of the most common attack vectors for unauthorized access and ransomware delivery.

Network Security Groups should never allow inbound RDP on port 3389 from source address prefixes such as `0.0.0.0/0`, `::/0`, `Internet`, or `*`. Access must be restricted to specific, trusted internal address ranges, or delivered through a VPN or Azure Bastion instead. This control also evaluates standalone `azurerm_network_security_rule` resources, not just inline `security_rule` blocks on the NSG itself.

This rule is covered by the [rdp-internet-restrict](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/rdp-internet-restrict.policy.hcl) policy.
