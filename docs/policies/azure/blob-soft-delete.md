# Ensure That Soft Delete for Blobs on Azure Blob Storage Storage Accounts is Enabled

| Provider | Category |
| -------- | -------- |
| Azure    | Storage security |

## Description

This control checks whether Azure Storage Accounts have blob soft delete enabled with a retention period of at least 7 days and no more than 365 days. Blob soft delete retains deleted blobs for a configurable period, allowing recovery from accidental or malicious deletion.

The CIS Azure Benchmark requires a minimum retention period of 7 days. Without soft delete, deleted blobs are permanently removed immediately and cannot be recovered. Storage accounts of kind `Storage` (V1) and `FileStorage` do not support blob properties and are excluded from enforcement.

This rule is covered by the [blob-soft-delete](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/storage/blob-soft-delete.policy.hcl) policy.
