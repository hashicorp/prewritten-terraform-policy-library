# Ensure that Logging for Azure Key Vault is Enabled

| Provider | Category |
| -------- | -------- |
| Azure    | Logging and monitoring |

## Description

This control checks that every Azure Key Vault has diagnostic logging enabled. Key Vault logs record who accessed keys, secrets and certificates and when, which is essential for auditing and incident response.

The policy evaluates `azurerm_key_vault` resources and looks up the `azurerm_monitor_diagnostic_setting` resources whose `target_resource_id` matches the vault. At least one matching setting must send logs to a destination (storage account, Log Analytics workspace, Event Hub or partner solution) and enable both the `audit` (or `AuditEvent`) and `allLogs` categories through `enabled_log`. A Key Vault with no diagnostic setting fails.

This rule is covered by the [keyvault-logging-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/keyvault/keyvault-logging-enabled.policy.hcl) policy.
