# Ensure That an Activity Log Alert Exists for Create Policy Assignment

| Provider | Category |
| -------- | -------- |
| Azure    | Logging and monitoring |

## Description

This control evaluates `azurerm_monitor_activity_log_alert` resources whose operation is `Microsoft.Authorization/policyAssignments/write`. Matching alerts must be enabled, use the `Administrative` category, include subscription scope, notify an action group, and have no additional caller, level, status, or resource criteria that narrow coverage.

The operation name is matched without case or surrounding whitespace. A declared scope list must include at least one subscription scope. Notification actions must include a nonblank action-group ID.

**Enforcement note:** This policy validates only declared activity-log alerts that match the create policy assignment operation. It cannot detect a missing alert; a plan with no matching alert does not establish that the subscription has the required monitoring.

Requires `hashicorp/azurerm >= 4.0.0, < 6.0.0`. Enforcement defaults to `advisory` and is configurable through `create-policy-assignment-alert-enforcement-level`.

This rule is covered by the [create-policy-assignment-alert](../../../policies/azure/monitor/create-policy-assignment-alert.policy.hcl) policy.
