# Ensure that HTTP(S) Access from the Internet is Evaluated and Restricted

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks whether Azure Network Security Group inline rules allow inbound HTTP (port 80) or HTTPS (port 443) traffic from Internet-level sources. Unrestricted inbound access on these ports exposes workloads to unauthorized access, reconnaissance, and exploitation from the public internet.

Network Security Groups should restrict inbound traffic to known, trusted source address ranges. Rules that allow TCP traffic on ports 80 or 443 from source address prefixes such as `0.0.0.0/0`, `Internet`, or `*` must be removed or narrowed to specific internal CIDRs.

This rule is covered by the [http-internet-restrict](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/http-internet-restrict.policy.hcl) policy.
