# Ensure that Application Gateway WAF Bot Protection is Enabled

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 7.15.

This control checks whether WAF_v2 Application Gateways are associated with a plan-visible WAF policy that enables `Microsoft_BotManagerRuleSet`. Bot protection helps identify automated traffic and known malicious bots.

The linked policy must be enabled, include the bot manager rule set, and not disable any `KnownBadBots` rules through rule-group overrides. An explicit `policy_settings.enabled = false` fails even when bot rules are configured. Omitted enabled settings use the provider default of `true`. Overrides for other bot groups do not substitute for protection against known bad bots.

**Enforcement note:** non-WAF_v2 gateways are outside scope. Missing or unresolved policy associations and references to external policies are deferred; a passing speculative result in these cases does not establish deployed bot protection. Inline WAF settings alone do not supply a bot manager rule set.

Enforcement defaults to `advisory` and can be configured with the `application-gateway-waf-bot-protection-enabled-enforcement-level` input.

This rule is covered by the [application-gateway-waf-bot-protection-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/application-gateway-waf-bot-protection-enabled.policy.hcl) policy.
