# Restrict SSH Access from the Internet

| Provider | Category               |
| -------- | ---------------------- |
| Azure    | Network security       |

## Description

CIS Azure Foundations v6.0.0 control 7.2 rejects allow rules exposing inbound TCP SSH on port 22 to Internet-level sources. Both inline Network Security Group rules and standalone `azurerm_network_security_rule` resources are evaluated.

The policy handles scalar and list fields, wildcard ports, and inclusive numeric port ranges. Internet-level sources include `*`, Internet, Any, bare `0.0.0.0`, and prefixes ending in `/0`, including IPv6. Known restricted sources are permitted; unknown ports and sources defer evaluation.

**Coverage:** The policy evaluates declared rules, not effective reachability, rule-priority interactions, or VM security assessments.

Requires `hashicorp/azurerm >= 4.0.0, < 6.0.0`. Enforcement defaults to `advisory`, configurable through `ssh-internet-restrict-enforcement-level`.

This rule is covered by the [ssh-internet-restrict](../../../policies/azure/network/ssh-internet-restrict.policy.hcl) policy.
