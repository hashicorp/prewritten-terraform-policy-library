# Regional Network Watcher Coverage

| Provider | Category               |
| -------- | ---------------------- |
| Azure    | Network security       |

## Description

CIS Azure Foundations v6.0.0 control 7.6 requires a Terraform-managed Network Watcher for each known region used by a declared virtual network. Locations are normalized for case and spaces. Known subscription IDs must match; unknown subscription IDs defer that comparison.

Unknown VNet regions defer evaluation. An unknown watcher region does not satisfy a known VNet region, and known blank watcher locations fail.

**Coverage:** Declared virtual networks approximate used regions, consistent with the benchmark-linked built-in policy. Regions used only by other resource types are not covered. AzureRM exposes no watcher enabled or provisioning-state attribute, so this policy validates declared regional coverage rather than runtime provisioning state.

Requires `hashicorp/azurerm >= 4.0.0, < 6.0.0`. Enforcement defaults to `advisory`, configurable through `network-watcher-enabled-enforcement-level`.

This rule is covered by the [network-watcher-enabled](../../../policies/azure/network/network-watcher-enabled.policy.hcl) policy.
