# Ensure that Application Gateway WAF Request Body Inspection is Enabled

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 7.14.

This control checks whether Azure Application Gateway WAF configurations disable request body inspection. Inspecting request bodies helps detect malicious payloads that are not visible in request URLs or headers alone.

Any inline `waf_configuration` and any exactly matched, plan-visible WAF policy must not set `request_body_check = false`. Omitted or null settings are treated as enabled in accordance with the defaults modeled by this policy.

**Enforcement note:** this control does not require a WAF configuration to exist. Missing configurations and external WAF policies cannot establish effective inspection settings; verify WAF presence and external settings separately.

Enforcement defaults to `advisory` and can be configured with the `application-gateway-waf-request-body-inspection-enabled-enforcement-level` input.

This rule is covered by the [application-gateway-waf-request-body-inspection-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/application-gateway-waf-request-body-inspection-enabled.policy.hcl) policy.
