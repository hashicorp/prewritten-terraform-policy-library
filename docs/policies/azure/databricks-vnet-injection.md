# Ensure that Azure Databricks is deployed in a customer-managed virtual network (VNet)

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks that every Azure Databricks workspace in the Terraform plan is deployed into a customer-managed virtual network (VNet injection). It evaluates `azurerm_databricks_workspace` resources and requires a `custom_parameters` block with a non-blank `virtual_network_id`, `public_subnet_name`, and `private_subnet_name`.

Deploying Databricks into a customer-managed VNet keeps cluster traffic on networks you control and lets you apply your own network security groups, routing, and peering. A workspace without `custom_parameters`, or with a blank VNet ID or subnet name, does not meet the control.

This rule is covered by the [databricks-vnet-injection](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/databricks/databricks-vnet-injection.policy.hcl) policy.
