# Virtual Network Flow Log Retention

| Provider | Category               |
| -------- | ---------------------- |
| Azure    | Network security       |

## Description

CIS Azure Foundations v6.0.0 control 7.8 evaluates flow logs with known virtual-network root-resource targets. Known retention days must be zero (unlimited) or at least 90.

Unknown target IDs and retention values defer evaluation. This is a retention-only check: it does not independently require logging or the retention-policy enabled flag to be enabled.

**Coverage:** Subnet and NIC targets are excluded even though the provider supports them. Missing flow logs are not detected. This batch's HCP verification used speculative plans only; no VNet flow log or storage account was created or applied.

Requires `hashicorp/azurerm >= 4.11.0, < 6.0.0`. Enforcement defaults to `advisory`, configurable through `vnet-flow-log-retention-enforcement-level`.

This rule is covered by the [vnet-flow-log-retention](../../../policies/azure/network/vnet-flow-log-retention.policy.hcl) policy.
