# Network Security Group Flow Log Retention

| Provider | Category               |
| -------- | ---------------------- |
| Azure    | Network security       |

## Description

CIS Azure Foundations v6.0.0 control 7.5 evaluates flow logs with known Network Security Group root-resource targets. Logging must not be explicitly disabled, and known retention days must be zero (unlimited) or at least 90.

Unknown target IDs and retention values defer evaluation. This policy does not add an independent requirement for the retention-policy enabled flag.

**Coverage:** Missing flow logs are not detected. New NSG flow-log creation is no longer supported; this check is for existing logs managed or imported into Terraform. AzureRM 5.8.0 rejected the reviewed creation fixture during planning, so no live create/destroy lifecycle was claimed for this control.

**HCP verification:** Plan-only tests with AzureRM 4.11.0 explicitly passed with 90-day retention ([compliant run](https://app.terraform.io/app/nagateja-test-org/azure_testing/runs/run-1rhDtTH9TZNkqBge)) and failed with 30-day retention ([noncompliant run](https://app.terraform.io/app/nagateja-test-org/azure_testing/runs/run-Nq6ocrx84aoVJCXC)). This historical provider version predates the creation guard observed with AzureRM 4.81.0. Neither plan was applied; these results verify policy evaluation, not current Azure support for creating NSG flow logs.

Requires `hashicorp/azurerm >= 4.11.0, < 6.0.0`. Enforcement defaults to `advisory`, configurable through `nsg-flow-log-retention-enforcement-level`.

This rule is covered by the [nsg-flow-log-retention](../../../policies/azure/network/nsg-flow-log-retention.policy.hcl) policy.
