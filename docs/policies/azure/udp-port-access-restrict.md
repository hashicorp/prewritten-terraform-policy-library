# Ensure that UDP Port Access from the Internet is Evaluated and Restricted

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks whether Azure Network Security Group inline rules or standalone Network Security Rules allow inbound UDP traffic from Internet-level sources to sensitive ports. Unrestricted inbound UDP access to ports 53 (DNS), 123 (NTP), 161 (SNMP), 389 (LDAP), and 1900 (SSDP/UPnP) can enable amplification attacks, information disclosure, and unauthorized service enumeration.

Network Security Groups and standalone security rules must not allow inbound UDP traffic from source address prefixes such as `0.0.0.0/0`, `Internet`, or `*` to the restricted ports listed above. Rules must be narrowed to specific, trusted source address ranges, or the protocol must be restricted to TCP only.

This rule is covered by the [udp-port-access-restrict](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/udp-port-access-restrict.policy.hcl) policy.
