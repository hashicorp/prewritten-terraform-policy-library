# Ensure Private Endpoints are Used to Access Azure Key Vault

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks that every Azure Key Vault in the Terraform plan has a corresponding `azurerm_private_endpoint`. The endpoint must include a `private_service_connection` whose `private_connection_resource_id` exactly matches the vault's resource ID.

Private Endpoints provide private connectivity to Key Vault and avoid exposing vault access over a public endpoint. A Private Endpoint for another vault, or one whose connection does not identify the vault, does not satisfy the check.

This rule is covered by the [private-endpoints-used](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/keyvault/private-endpoints-used.policy.hcl) policy.
