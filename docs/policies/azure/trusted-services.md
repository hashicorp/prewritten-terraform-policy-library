# Ensure 'Allow trusted Microsoft services to access this resource' is Enabled for Storage Account Access

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks whether Azure Storage Accounts that have network rules with a default action of `Deny` include `AzureServices` in the bypass list. When network rules block all traffic by default, trusted Microsoft services such as Azure Backup, Azure Monitor, and Azure Event Grid must be explicitly allowed to bypass the network restrictions in order to continue functioning.

Without `AzureServices` in the bypass list, critical Azure platform services lose access to the storage account, which can disrupt backups, monitoring, and other integrated services. This policy evaluates both inline `network_rules` blocks and standalone `azurerm_storage_account_network_rules` resources. Using both simultaneously on the same storage account is a configuration error and is also flagged by this policy.

This rule is covered by the [trusted-services](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/storage/trusted-services.policy.hcl) policy.
