# Ensure That Microsoft Defender for App Services Is Set To 'On'

| Provider | Category |
| -------- | -------- |
| Azure    | Security posture management |

## Description

This control checks that Microsoft Defender for App Service is enabled at the Standard tier. It evaluates `azurerm_security_center_subscription_pricing` resources with `resource_type = "AppServices"`.

The Standard plan provides threat detection for Azure App Service. A Free tier, blank tier, omitted tier, or other tier does not meet the control.

This rule is covered by the [security-center-defender-app-services-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/security-center/security-center-defender-app-services-enabled.policy.hcl) policy.
