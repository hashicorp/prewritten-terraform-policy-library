# Ensure that an Activity Log Alert Exists for Delete SQL Server Firewall Rule

| Provider | Category |
| -------- | -------- |
| Azure    | Logging and monitoring |

## Description

This control checks that an enabled Azure Activity Log alert with an action group exists for the administrative operation `Microsoft.Sql/servers/firewallRules/delete` whenever the Terraform plan contains an `azurerm_mssql_server` or `azurerm_mssql_firewall_rule` resource.

The alert must use the `Administrative` category and have at least one action group with a non-empty `action_group_id`. This ensures that deletion of a SQL Server firewall rule can trigger a notification or response.

The policy evaluates only SQL Server and SQL firewall rule resources, so plans without SQL resources are not checked. The qualifying alert can be anywhere in the plan and is not tied to a specific SQL Server.

This rule is covered by the [firewall-rule-delete-alert](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/sql/firewall-rule-delete-alert.policy.hcl) policy.
