# Ensure That Microsoft Defender for Open-Source Relational Databases Is Set To 'On'

| Provider | Category |
| -------- | -------- |
| Azure    | Security posture management |

## Description

This control checks that Microsoft Defender for open-source relational databases is enabled at the Standard tier. It evaluates `azurerm_security_center_subscription_pricing` resources with `resource_type = "OpenSourceRelationalDatabases"`. The resource type and tier are compared case-insensitively.

The Standard plan provides threat detection for Azure Database for PostgreSQL, MySQL, and MariaDB. A Free tier, omitted tier, or other tier does not meet the control.

This rule is covered by the [defender-open-source-relational-databases-on](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/security-center/defender-open-source-relational-databases-on.policy.hcl) policy.
