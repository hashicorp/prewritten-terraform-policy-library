# Ensure Soft Delete for Azure File Shares is Enabled

| Provider | Category |
| -------- | -------- |
| Azure    | Storage security |

## Description

This control checks whether Azure Storage Accounts have file share soft delete enabled with a retention period between 1 and 365 days. File share soft delete preserves deleted file shares and their contents for a configurable retention period, allowing recovery from accidental or malicious deletion.

Without soft delete, deleted Azure file shares are permanently removed and cannot be recovered. Enabling this feature provides an important data recovery mechanism for shared file storage. Only `StorageV2` and `FileStorage` account kinds support file shares — accounts of other kinds such as `BlobStorage` and `BlockBlobStorage` are excluded from enforcement.

This rule is covered by the [file-share-soft-delete](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/storage/file-share-soft-delete.policy.hcl) policy.
