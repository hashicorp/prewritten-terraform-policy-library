# Ensure 'Allow Public Network Access' is set to 'Disabled'

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control checks that public network access is disabled on every Azure Databricks workspace. It evaluates `azurerm_databricks_workspace` resources and requires `public_network_access_enabled = false`. Because disabling public access requires a private front end, the workspace must also use VNet injection (a non-blank `virtual_network_id`, `public_subnet_name`, and `private_subnet_name` in `custom_parameters`) and set `network_security_group_rules_required` to `NoAzureDatabricksRules` or `NoAzureServiceRules`.

Disabling public network access blocks workspace access from the public internet. An omitted `public_network_access_enabled` value is treated as enabled, because that is the provider default, and does not meet the control.

This rule is covered by the [databricks-public-network-access-disabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/databricks/databricks-public-network-access-disabled.policy.hcl) policy.
