# Ensure that Microsoft Defender for Cloud Checks VM Operating Systems for Updates

| Provider | Category |
| -------- | -------- |
| Azure    | Security posture management |

## Description

This control checks that virtual machines are configured to periodically check for missing system updates. It maps to the Azure Policy definition `bd876905-5b84-4f73-ab2d-2e7a7c4568d9` (Machines should be configured to periodically check for missing system updates) used in the CIS audit.

The policy evaluates `azurerm_linux_virtual_machine` and `azurerm_windows_virtual_machine` resources. A VM passes when it sets `patch_assessment_mode = "AutomaticByPlatform"`, or when the plan contains an enforced assignment of policy definition `bd876905-5b84-4f73-ab2d-2e7a7c4568d9` that covers it: a subscription or management group assignment, a resource group assignment for the VM's resource group, or a resource assignment for the VM itself. A missing or `ImageDefault` assessment mode fails unless such an assignment is present.

The other half of the CIS audit, that no "System updates should be installed on your machines" recommendations (`f85bf3e0-d513-442e-89c3-1784ad63382b`) are open, depends on the runtime state of the machines and cannot be evaluated from a Terraform plan. Assignments made outside this Terraform configuration are also not visible to the policy.

This rule is covered by the [defender-vm-os-updates](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/security-center/defender-vm-os-updates.policy.hcl) policy.
