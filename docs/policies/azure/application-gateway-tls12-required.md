# Ensure that Application Gateway SSL Policies Require TLS 1.2 or Later

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 7.12.

This control checks configured Azure Application Gateway SSL policies, including policies within SSL profiles, for TLS 1.2 or TLS 1.3. Older protocol versions provide weaker protection for traffic between clients and applications.

Custom and CustomV2 policies must declare `min_protocol_version` as `TLSv1_2` or `TLSv1_3`. Predefined policies must use `AppGwSslPolicy20170401S`, `AppGwSslPolicy20220101`, or `AppGwSslPolicy20220101S`, which are the verified TLS 1.2 predefined policies accepted by this control.

**Enforcement note:** this policy checks explicit SSL policy settings. Absent policies and unresolved values do not prove the service's effective TLS minimum; verify Azure defaults and resolved settings separately.

Within a declared Custom or CustomV2 policy, an omitted minimum version fails. Within a declared Predefined policy, an omitted policy name fails. Schema-aware test omission is not evidence of a computed unknown.

Enforcement defaults to `advisory` and can be configured with the `application-gateway-tls12-required-enforcement-level` input.

This rule is covered by the [application-gateway-tls12-required](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/application-gateway-tls12-required.policy.hcl) policy.
