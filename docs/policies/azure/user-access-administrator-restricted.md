# Ensure That Use of the User Access Administrator Role Is Restricted

| Provider | Category |
| -------- | -------- |
| Azure    | Identity and access management |

## Description

This control implements CIS Azure Foundations Benchmark 5.3.3 by rejecting the built-in User Access Administrator role at root scope `/` in `azurerm_role_assignment`, `azurerm_pim_active_role_assignment`, and `azurerm_pim_eligible_role_assignment` resources. The role ID ends in `18d7d88d-d35e-4fb5-a5c3-7773c20a72d9`.

For ordinary assignments, an explicit role ID is authoritative; when no ID is supplied, the policy checks the normalized role name. PIM assignments are checked by ID. Supplying an explicit ID avoids dependence on an unknown computed role name during planning.

The restriction applies specifically to root-scoped assignments of the built-in User Access Administrator role. Subscription, management-group, and resource-group assignments are outside this control's scope.

Requires `hashicorp/azurerm >= 4.0.0, < 6.0.0`. Enforcement defaults to `advisory` and is configurable through `user-access-administrator-restricted-enforcement-level`.

This rule is covered by the [user-access-administrator-restricted](../../../policies/azure/iam/user-access-administrator-restricted.policy.hcl) policy.
