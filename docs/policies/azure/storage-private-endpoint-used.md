# Ensure that Storage Accounts Have Declared Private Endpoint Connections

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 9.3.2.1.

This control checks whether each Azure storage account has a Terraform-declared private endpoint connection. Private endpoints allow access over private network addresses instead of relying on public service connectivity.

An `azurerm_private_endpoint` must have a `private_service_connection` whose `private_connection_resource_id` exactly matches the storage account ID, ignoring case, and whose `is_manual_connection` is `false`. Each storage account needs its own matching endpoint; an endpoint for another account does not satisfy the requirement.

**Enforcement note:** unresolved IDs can produce unknown results in speculative plans. Declaring an automatic connection does not prove that Azure has approved it or that every required virtual network has an endpoint. Verify connection status, required storage subresources, and network coverage in Azure.

Enforcement defaults to `advisory` and can be configured with the `storage-private-endpoint-used-enforcement-level` input.

This rule is covered by the [storage-private-endpoint-used](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/storage/storage-private-endpoint-used.policy.hcl) policy.
