# CloudWatch log groups should be retained for a specified time period

| Provider            | Category |
| ------------------- | -------- |
| Amazon Web Services | Logging |

## Description

This control checks whether Amazon CloudWatch log groups have a retention period of at least 365 days or are configured to never expire. The control fails if `retention_in_days` is absent, null, or set to a value between 1 and 364 (inclusive). A value of `0` (never expire) is also considered compliant.

Retaining CloudWatch log groups for a minimum of one year ensures that audit trails, application logs, and security event data remain available for incident investigation, forensic analysis, and compliance reporting. Many regulatory frameworks — including PCI DSS, HIPAA, and NIST 800-53 — require that security-relevant logs be retained for at least one year. Setting `retention_in_days = 0` is permitted for use cases where indefinite retention is required.

This rule is covered by the [cloudwatch-log-groups-should-be-retained-for-a-specified-time-period](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/cloudwatch/cloudwatch-log-groups-should-be-retained-for-a-specified-time-period.policy.hcl) policy.
