# CloudTrail trails should have logging enabled

| Provider            | Category |
| ------------------- | -------- |
| Amazon Web Services | Logging |

## Description

This control checks whether AWS CloudTrail trails have logging turned on. A trail that has logging disabled (`enable_logging = false`) stops recording API activity, which removes the audit trail that is needed for security analysis, resource change tracking, and compliance auditing.

The policy evaluates each `aws_cloudtrail` resource. It is non-compliant when the `enable_logging` attribute is explicitly set to `false`. When the attribute is omitted or `null`, Terraform applies the AWS default of `true`, so the trail is treated as compliant.

This rule is covered by the [cloudtrail-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/cloudtrail/cloudtrail-enabled.policy.hcl) policy.
