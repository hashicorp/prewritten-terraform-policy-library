# Bedrock AgentCore Gateway should be encrypted with customer managed AWS KMS keys

| Provider            | Category |
| ------------------- | -------- |
| Amazon Web Services | Encryption of data-at-rest |

## Description

This control checks whether Amazon Bedrock AgentCore gateways are encrypted at rest with a customer managed AWS KMS key. Using a customer managed key gives you control over the key policy, rotation, and access auditing, which an AWS owned or AWS managed key does not.

The policy evaluates each `aws_bedrockagentcore_gateway` resource. It is non-compliant when the `kms_key_arn` attribute is missing, `null`, or an empty string, or when it references an AWS managed key alias (`alias/aws/...`).

This rule is covered by the [bedrockagentcore-gateway-encrypted-cmk](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/bedrock/bedrockagentcore-gateway-encrypted-cmk.policy.hcl) policy.
