# Non-default security groups should be attached to an elastic network interface

| Provider | Category |
| ------------------- | -------- |
| Amazon Web Services | Inventory |

## Description

This policy checks if non-default security groups are attached to elastic network interfaces. The policy fails if the security group is not associated with a network interface.

The policy evaluates `aws_security_group` resources.

- The security group ID is computed. For a security group created in the same plan, the ID and every reference to it are unknown until apply, so the result is unknown at plan time. Existing (imported or already applied) security groups are evaluated.

This rule is covered by the [ec2-non-default-security-groups-attached-to-eni](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/ec2/ec2-non-default-security-groups-attached-to-eni.policy.hcl) policy.
