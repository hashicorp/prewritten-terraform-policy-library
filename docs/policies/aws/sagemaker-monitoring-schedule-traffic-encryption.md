# SageMaker monitoring schedules should have inter-container traffic encryption enabled

| Provider            | Category |
| ------------------- | -------- |
| Amazon Web Services | Encryption of data-in-transit |

## Description

This control checks whether an Amazon SageMaker AI monitoring schedule has encryption enabled for inter-container traffic. The control fails if the monitoring job definition does not have encryption enabled for inter-container traffic.

The policy evaluates each `aws_sagemaker_monitoring_schedule` resource. When the schedule defines its job inline (`monitoring_schedule_config.monitoring_job_definition`), `network_config.enable_inter_container_traffic_encryption` must be `true`; an omitted `network_config` or flag is non-compliant. When the schedule references a job definition by `monitoring_job_definition_name`, the policy checks the matching `aws_sagemaker_data_quality_job_definition` in the plan. A referenced definition that is not in the plan, or that is an `awscc_*` job definition, cannot be evaluated and is not reported.

This rule is covered by the [sagemaker-monitoring-schedule-traffic-encryption](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/sagemaker/sagemaker-monitoring-schedule-traffic-encryption.policy.hcl) policy.
