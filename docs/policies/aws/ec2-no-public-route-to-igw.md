# Route tables should not have unrestricted routes to an internet gateway

| Provider | Category |
| ------------------- | -------- |
| Amazon Web Services | Secure network configuration |

## Description

This policy checks if there are public routes in the route table to an Internet gateway (IGW). The policy fails if a route to an IGW has a destination CIDR block of '0.0.0.0/0' or '::/0' or if a destination CIDR block does not match the rule parameter.

The policy evaluates `aws_route`, `aws_route_table` resources.

- A `gateway_id` that references an Internet Gateway created in the same plan is unknown until apply, so the `igw-` prefix check cannot run and the result is unknown.

This rule is covered by the [ec2-no-public-route-to-igw](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/ec2/ec2-no-public-route-to-igw.policy.hcl) policy.
