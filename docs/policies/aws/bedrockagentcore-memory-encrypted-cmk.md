# Bedrock AgentCore Memory should be encrypted with customer managed AWS KMS keys

| Provider            | Category |
| ------------------- | -------- |
| Amazon Web Services | Encryption of data-at-rest |

## Description

This control checks whether Amazon Bedrock AgentCore memory resources are encrypted at rest with a customer managed AWS KMS key. Agent memory can hold conversation history and other sensitive context, so encrypting it with a key that you control lets you manage key policy, rotation, and access auditing.

The policy evaluates each `aws_bedrockagentcore_memory` resource. It is non-compliant when the `encryption_key_arn` attribute is missing, `null`, or an empty string, or when it references an AWS managed key alias (`alias/aws/...`).

This rule is covered by the [bedrockagentcore-memory-encrypted-cmk](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/aws/bedrock/bedrockagentcore-memory-encrypted-cmk.policy.hcl) policy.
