# Ensure RSASHA1 Is Not Used for the Key-Signing Key in Cloud DNS DNSSEC

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Networking |

## Description

This control checks the `default_key_specs` of each planned `google_dns_managed_zone`. It flags `RSASHA1` when used by a spec whose `key_type` is `keySigning`; use of `RSASHA1` for a `zoneSigning` key is not flagged by this control.

When `dnssec_config` or `default_key_specs` is absent, service-side defaults are not available in the Terraform plan, so the policy evaluates only explicitly configured key specs. It does not assess zones managed outside Terraform.

This rule is covered by the [dns-zone-dnssec-ksk-no-rsasha1](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/network/dns-zone-dnssec-ksk-no-rsasha1.policy.hcl) policy.
