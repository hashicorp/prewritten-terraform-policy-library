# Ensure Logging Is Enabled for HTTP(S) Load Balancers

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Networking |

## Description

This control checks `google_compute_backend_service` and `google_compute_region_backend_service` resources for `log_config.enable = true` and a positive `sample_rate`. If `sample_rate` is absent, the policy treats it as the documented provider default of `1.0`; missing or null logging configuration and enablement are treated as disabled.

The policy approximates HTTP(S) scope using the backend service protocol: `TCP`, `SSL`, `UDP`, and `UNSPECIFIED` are excluded, while an absent protocol is treated as the provider-default HTTP. It does not verify that a backend service is actually attached to an HTTPS frontend. The requirement that the sample rate be appropriate for the organization is not evaluated; only zero or negative rates are rejected. The policy evaluates resources in the Terraform plan and cannot see logging configured outside it.

This rule is covered by the [compute-load-balancer-logging-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/compute-load-balancer-logging-enabled.policy.hcl) policy.
