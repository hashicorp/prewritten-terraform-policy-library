# Ensure That Instances Are Not Configured To Use the Default Service Account With Full Access to All Cloud APIs

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Compute security |

## Description

This control checks whether a `google_compute_instance` that uses the project's default Compute Engine service account (or omits `service_account.email` entirely, which resolves to the same default account) also grants the `cloud-platform` OAuth scope, either as the short name `"cloud-platform"` or the full URL `https://www.googleapis.com/auth/cloud-platform`.

The `cloud-platform` scope grants an instance access to all enabled Google Cloud APIs, subject only to the IAM permissions of its attached service account. Combined with the default service account's broad `Editor`-level project access, this effectively gives the instance nearly unrestricted access to the project's Cloud APIs. If the instance is compromised, an attacker inherits that same broad access. Instances should instead use a custom, narrowly-scoped service account, or at minimum restrict the OAuth scopes granted to the default account to only what the workload requires.

This rule is covered by the [4-2-default-sa-scopes](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/compute/4-2-default-sa-scopes.policy.hcl) policy.
