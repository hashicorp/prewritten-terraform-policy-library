# Ensure "Enable Connecting to Serial Ports" Is Not Enabled for VM Instance

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Compute security |

## Description

This control checks that a `google_compute_instance` either omits the `serial-port-enable` metadata key or sets it to a falsy value. GCP treats this metadata value as case-insensitive and accepts several falsy aliases (`false`, `FALSE`, `N`, `No`, `0`); any of these are treated as compliant, while any other value (including an empty string) is treated as enabling serial port access.

The interactive serial console provides a text-based, password-based connection to a VM that bypasses normal network-level access controls such as firewall rules and SSH key management. Because it is authenticated separately (via IAM, not VPC firewalls), leaving it enabled expands the instance's attack surface with a channel that isn't covered by network security controls. Disabling serial port access ensures all interactive access to the instance goes through standard, auditable network paths (e.g. SSH) instead.

This rule is covered by the [4-5-serial-ports](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/compute/4-5-serial-ports.policy.hcl) policy.
