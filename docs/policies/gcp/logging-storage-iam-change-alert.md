# Ensure That the Log Metric Filter and Alerts Exist for Cloud Storage IAM Permission Changes

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging and monitoring |

## Description

This control checks for a log metric using `resource.type="gcs_bucket" AND protoPayload.methodName="storage.setIamPermissions"` and an enabled alert policy whose `condition_threshold.filter` references that metric's `metric.type`. The alert must also have at least one notification channel. The metric filter may use quoted or unquoted `gcs_bucket` syntax.

The Google provider defaults an omitted `enabled` value to true; an explicitly disabled alert does not qualify. The policy cannot assess a plan with no metric or alert-policy resources because there is no resource to anchor the project-level check. Notification-channel suitability and alert thresholds remain organization-specific.

This rule is covered by the [logging-storage-iam-change-alert](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/logging-storage-iam-change-alert.policy.hcl) policy.
