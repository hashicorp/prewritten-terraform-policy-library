# Ensure That Cloud KMS Cryptokeys Are Not Anonymously or Publicly Accessible

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Identity and access management |

## Description

This control checks that Cloud KMS crypto key IAM policies do not grant access to `allUsers` or `allAuthenticatedUsers`. These principals provide access to anyone or to any authenticated Google account, respectively. The policy checks Terraform's `google_kms_crypto_key_iam_member`, `google_kms_crypto_key_iam_binding`, and `google_kms_crypto_key_iam_policy` resources, and inspects only members in IAM policy bindings.

The check evaluates the Terraform plan only. IAM grants made outside Terraform, such as through the Google Cloud Console or `gcloud`, are not evaluated.

This rule is covered by the [kms-crypto-key-no-public-access](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/iam/kms-crypto-key-no-public-access.policy.hcl) policy.
