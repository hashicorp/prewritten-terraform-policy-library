# Ensure Log Metric Filter and Alerts Exist for Project Ownership Assignments and Changes

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging and monitoring |

## Description

This control checks ownership-related `google_logging_metric` resources for the prescribed Cloud Resource Manager filter: project ownership/invite events, plus ADD and REMOVE changes to `roles/owner`. Each matching metric must be referenced by an enabled `google_monitoring_alert_policy` condition threshold.

When `enabled` is omitted, the Google provider defaults the alert policy to enabled. Explicitly disabled alerts do not satisfy the requirement. The check cannot flag a plan with no ownership-related logging metric because there is no metric resource to evaluate. Notification-channel appropriateness and alert threshold suitability are organization-specific and are not enforced.

This rule is covered by the [logging-project-ownership-change-alert](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/logging-project-ownership-change-alert.policy.hcl) policy.
