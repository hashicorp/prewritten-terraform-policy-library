# Ensure RSASHA1 Is Not Used for the Zone-Signing Key in Cloud DNS DNSSEC

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Networking |

## Description

This control checks every configured `default_key_specs` entry in planned `google_dns_managed_zone` resources. It flags `RSASHA1` when used by a spec whose `key_type` is `zoneSigning`; an RSASHA1 key-signing key alone does not violate this control.

When `dnssec_config` or `default_key_specs` is omitted, Google may apply service-side default key specs that are not available in the Terraform plan. The policy therefore evaluates only explicitly configured zone-signing key specs and does not assess zones managed outside Terraform.

This rule is covered by the [dns-zone-dnssec-zsk-no-rsasha1](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/network/dns-zone-dnssec-zsk-no-rsasha1.policy.hcl) policy.
