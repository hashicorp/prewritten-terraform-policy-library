# Ensure That the Log Metric Filter and Alerts Exist for Audit Configuration Changes

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging and monitoring |

## Description

This control checks whether a `google_logging_metric` uses the prescribed filter `protoPayload.methodName="SetIamPolicy" AND protoPayload.serviceData.policyDelta.auditConfigDeltas:*`, and whether an enabled `google_monitoring_alert_policy` condition threshold references that metric by its exact `metric.type`.

Filters containing either required clause but combining them incorrectly (for example, with `OR` or `NOT`) are rejected. Unrelated metrics are outside this check. The Google provider defaults an omitted alert-policy `enabled` value to `true`; an explicitly disabled alert does not satisfy the requirement.

The policy cannot detect a plan with no `google_logging_metric` resource because there is no metric resource to evaluate. It also cannot verify that notification channels are appropriate or that thresholds suit the organization; those are manual requirements.

This rule is covered by the [logging-audit-config-change-alert](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/logging-audit-config-change-alert.policy.hcl) policy.
