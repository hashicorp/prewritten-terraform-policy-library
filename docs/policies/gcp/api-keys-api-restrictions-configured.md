# Ensure API Keys Are Restricted to Only APIs That an Application Needs Access To

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Identity and access management |

## Description

This control checks whether each Terraform `google_apikeys_key` has at least one API target in `restrictions.api_targets`. The key must not target `cloudapis.googleapis.com`, which represents all Google Cloud APIs. Browser, server, or other client restrictions alone do not satisfy the API restriction requirement.

API restrictions can break existing applications if they omit a service the application uses. The policy evaluates key resources in the Terraform plan; the current test run checks policy behavior structurally and does not verify resource attributes against the Google provider schema.

This rule is covered by the [api-keys-api-restrictions-configured](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/iam/api-keys-api-restrictions-configured.policy.hcl) policy.
