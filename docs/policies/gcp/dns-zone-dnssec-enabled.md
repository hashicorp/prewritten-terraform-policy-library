# Ensure DNSSEC Is Enabled for Public Cloud DNS Zones

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Networking |

## Description

This control checks each planned `google_dns_managed_zone` and requires `dnssec_config.state = "on"`, except for zones whose `visibility` is explicitly `private`. Missing, null, or empty DNSSEC state is treated as disabled. Missing, null, or empty visibility is conservatively treated as in scope rather than assumed private.

The policy evaluates only zones in the Terraform plan. It does not verify DNSSEC configuration managed outside Terraform or validate DNSSEC delegation beyond the managed-zone state.

This rule is covered by the [dns-zone-dnssec-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/network/dns-zone-dnssec-enabled.policy.hcl) policy.
