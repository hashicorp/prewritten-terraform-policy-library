# Ensure Essential Contacts Is Configured for the Organization

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Identity and access management |

## Description

This control checks that organization-scoped `google_essential_contacts_contact` resources provide a non-empty email address and cover either the `ALL` notification category or all of `LEGAL`, `SECURITY`, `SUSPENSION`, and `TECHNICAL`. Coverage may be split across multiple contacts for the same organization. Project- and folder-scoped contacts are outside this control.

The policy evaluates contacts present in the Terraform plan. An organization with no `google_essential_contacts_contact` resource cannot be detected because there is no resource to evaluate. The policy can check that an email is non-empty, but cannot determine whether it is a real, monitored address.

This rule is covered by the [essential-contacts-configured](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/iam/essential-contacts-configured.policy.hcl) policy.
