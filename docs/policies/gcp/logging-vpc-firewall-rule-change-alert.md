# Ensure That the Log Metric Filter and Alerts Exist for VPC Network Firewall Rule Changes

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging and monitoring |

## Description

This control checks for a log metric with the filter `resource.type="gce_firewall_rule" AND (protoPayload.methodName:"compute.firewalls.patch" OR protoPayload.methodName:"compute.firewalls.insert" OR protoPayload.methodName:"compute.firewalls.delete")`. The metric must be referenced by an enabled alert policy that has at least one notification channel. The three method clauses may appear in any order and may use `v1.`, `beta.`, or `alpha.` method prefixes. Negation, additional clauses, and missing or duplicate operations do not satisfy the check.

The policy evaluates alert references in threshold and absent conditions. It does not inspect MQL, PromQL, or SQL conditions. A plan with no logging metric or alert-policy resources cannot be evaluated because there is no resource to anchor the policy on. Alert thresholds must be reviewed for the organization.

This rule is covered by the [logging-vpc-firewall-rule-change-alert](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/logging-vpc-firewall-rule-change-alert.policy.hcl) policy.
