# Ensure That Sinks Are Configured for All Log Entries

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging and monitoring |

## Description

This control checks sinks declared in the Terraform plan across project, folder, organization, and billing-account scopes. At least one sink must be enabled, have no inclusion filter, have a non-empty destination, and have no enabled exclusions so that it routes all log entries. Explicitly disabled exclusions do not disqualify a sink.

The policy cannot flag an environment with no sink resources in the plan because there is no sink resource to evaluate. Sinks managed outside the plan are not visible. Destination presence is checked, but the policy does not verify that the referenced bucket, dataset, topic, or other destination resource exists.

This rule is covered by the [logging-sinks-all-entries](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/logging/logging-sinks-all-entries.policy.hcl) policy.
